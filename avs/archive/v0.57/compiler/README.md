# Archived v0.57 compiler AVS fixtures

This directory preserves the retired v0.57 curated assembly fixture, its
`L.BSTART` matrix checker, and the former negative `L.BSTOP` test for
historical investigation only. They are not part of the v0.58.1 compiler AVS
runner, coverage, or conformance evidence.

Do not copy these archived sources back into an active test path. Current
compiler AVS assembly coverage lives under
`avs/compiler/linx-llvm/tests/asm/` and is routed against the v0.58 catalog.
