# LinxISA v0.56.5

LinxISA v0.56.5 is a maintenance release of the canonical `isa/v0.56`
profile. The checked-in JSON and opcode sources remain the normative source;
generated codecs, Sail decode, manuals, and downstream consumers are validated
projections of that source.

## Contract changes

- `B.IOD`, `B.IOTI`, `B.ATTR`, and the `BSTART.PAR` spelling are retired and rejected. The `B.IOD`
  encoding is reserved; the former parallel-block form decodes only as
  `BSTART.TEPL`.
- Bare `BSTART.CALL` preserves `ra`. A returning call requires an adjacent
  `SETRET` or `C.SETRET` with an explicit return label.
- Sail coverage is tracked by stable instruction form ID and is graded as
  decode-only, executable subset, or architecturally complete.
- Sail 0.20.2 with OCaml 4.14 is the pinned parser and typechecker toolchain.
- The source-policy name is `linx-v056`; no compatibility alias is accepted.

## Repository maintenance

- English documentation is the normative site; Chinese is a validated
  secondary translation.
- `tools/LinxCoreModel` is the only LinxCoreModel gitlink.
- Required QEMU lanes use an explicit clean binary and canonical opcode
  metadata.
- TSVC uses shared freestanding runtime services and the canonical finisher.
- Tracked WaveDrom dependencies are removed and reproduced with `npm ci`.
