# LinxISA 0.59.1 specification release

Tag `v0.59.1` publishes the architecture specification, binary encodings and assembled Sail model. Select profile `v0.59` for this edition. The superproject continues to select `v0.58` by default for platform bring-up. Compiler, emulator, operating system and RTL qualification are tracked independently. [Profile selection](https://github.com/LinxISA/linx-isa/blob/v0.59.1/isa/profile-selection.json) · [Release manifest](https://github.com/LinxISA/linx-isa/blob/v0.59.1/isa/v0.59/release_manifest.json)

## Specification and provenance

The catalog contains 1,499 instruction forms under 754 catalog mnemonic names. These comprise 473 unqualified scalar forms, 105 command forms, 216 Linx-specific forms and 705 scoped 64-bit forms. The 119 direct Tile operations use selectors in command encodings. They are counted separately. The profile also imports 100 system-register definitions and 50 PTO extension-space reservations. The published upstream PTO source is `a89a53d48f5708328be609fe2e6296ac8bdb4bc2` (tag `v0.59.1.0`). [Catalog](https://github.com/LinxISA/linx-isa/blob/v0.59.1/isa/v0.59/linxisa-v0.59.json) · [Source lock](https://github.com/LinxISA/linx-isa/blob/v0.59.1/isa/v0.59/pto-spec.lock.json)

The ELF identity uses release `0.59.1`, ABI `pto-isa-0.59.1-mode-function-v1`, and projection SHA-256 `d90c881754d66f2cd26f6014d0b582cba88307e70123583d87fc59a918229c28`. The 578 common forms retain their fixed bits. The allowed domains expand for `B.DATR.CMode` and `BSTART.TMOV.DataType`. The 705 scoped carriers occupy space disjoint from the 194 retained 64-bit Linx forms. [Encoding alignment](https://github.com/LinxISA/linx-isa/blob/v0.59.1/docs/architecture/v0.59.1-pto-alignment.md)

## Sail and checks

From the tag, run the following with Sail 0.20.2 on PATH. The export includes the decoder generated from the 1,499-form catalog, the canonical model entry, a file manifest and checksums. The assembled check exercises the parser, directed tests and C backend. The scoped execution interface models requests, blocking, completion, faults and retirement. Its platform interface supplies memory and ordering effects. [Sail toolchain](https://github.com/LinxISA/linx-isa/blob/v0.59.1/isa/sail/toolchain.json)

```sh
python3 tools/isa/select_linxisa_profile.py --profile v0.59
python3 tools/isa/build_golden.py --profile v0.59 --check
python3 tools/isa/validate_spec.py --profile v0.59
python3 tools/isa/check_pto_v0591_alignment.py
python3 tools/isa/check_v0591_candidate_dispatch_sail.py
python3 tools/isa/export_linxisa_v0591_sail.py --output /tmp/linxisa-0591-sail
python3 tools/isa/export_linxisa_v0591_sail.py --check /tmp/linxisa-0591-sail
```

## System validation at specification publication

| Surface | Evidence and remaining work |
| --- | --- |
| LLVM and QEMU | Eleven QEMU oracle suites produced ELFs with the locked 0.59.1 identity. All 71 sampled forms had admitted execution and result evidence. Both numeric and symbolic scoped-scalar runs compared 180 carriers and 1,440 result bytes across QEMU, linx-model, gfrun and gfsim. This is sampled coverage. The LLVM diagnostic vectorized 122 of 151 TSVC kernels against the existing floor of 148. Active-replay lowering still needs a legal branch-free implementation. [AVS](https://github.com/LinxISA/linx-isa/pull/239) · [LLVM](https://github.com/LinxISA/llvm-project/pull/182) |
| LinxCore RTL | Opcode parity and stage connectivity passed on a candidate revision. Runner and cosimulation stopped in the pyCircuit JIT at the historical `Wire._zext` API. RTL execution parity remains open. [LinxCore](https://github.com/LinxISA/LinxCore/pull/55) |
| Linux | Initramfs smoke and full boot passed. A diagnostic kernel with scatter-gather pool initialization and paced UART input also completed the BusyBox block-rootfs test. Final merged kernel and rootfs pins require a fresh build and rerun. [Linux](https://github.com/LinxISA/linux/pull/36) |
| Integrated system | Final component pins, runtime-convergence reports from both required lanes and full system qualification remain open. The specification tag carries no full-system pass. [Component pins](https://github.com/LinxISA/linx-isa/pull/230) · [System qualification](https://github.com/LinxISA/linx-isa/pull/237) |
