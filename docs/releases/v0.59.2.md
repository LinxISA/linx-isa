# LinxISA v0.59.2 specification release

The v0.59.2 machine-readable catalog marks **193 of 1,499 instruction forms obsolete**. Select profile `v0.59.2` for the architecture specification, encodings and Sail package. The detailed decision lists every affected mnemonic and the block-entry masks. [Architecture decision](../architecture/linx-two-level-block-obsolescence.md) · [Release catalog](https://github.com/LinxISA/linx-isa/blob/v0.59.2/isa/v0.59.2/linxisa-v0.59.2.json)

[Download the Chinese HTML manual](https://github.com/LinxISA/linx-isa/releases/download/v0.59.2/linxisa-0.59.2-html.zip). Extract the ZIP and open `index.html` to browse 1,306 encoding forms and 119 Tile operations.

| Architecture status | Forms | Scope |
| --- | ---: | --- |
| Obsolete | 193 | All 184 `V.*` forms, the eight ordinary and compressed MSEQ/MPAR/VSEQ/VPAR block entries, and `B.TEXT` |
| Retained Linx extensions | 19 | `HL.BSTART.CALL` and the 48-bit and 64-bit extended FP, STD and SYS block headers |
| Encoding reservation only | 4 | `DMA.FREE.L`, `DMA.FREE.S`, `MCOPY.DL`, `MCOPY.DS`. Execution must reject before reading operands or producing architectural effects |
| Shared with PTO | 1,283 | 578 base scalar/command forms and 705 scoped scalar forms |

The 193 obsolete forms occupy ten PTO encoding reservations. All of those bit patterns remain reserved. The 119 Tile operations, including the 32 Tile VEC operations, are a separate inventory. The PTO source lock, instruction encodings and ELF ABI match the 0.59.1 specification. Software that needs to identify this edition should select the Linx specification version; an ELF identity identifies the shared encoding ABI. [PTO source lock](https://github.com/LinxISA/linx-isa/blob/v0.59.2/isa/v0.59/pto-spec.lock.json)

The 216 Linx-only rows carry an `architecture_status.state` field. The 193 obsolete rows have the value `obsolete`.

## Reproduce the release

From a checkout of the tag, run:

```sh
python3 tools/isa/select_linxisa_profile.py --profile v0.59.2 --require-release-qualified
python3 tools/isa/build_golden.py --profile v0.59.2 --check
python3 tools/isa/validate_spec.py --profile v0.59.2
python3 tools/isa/export_linxisa_v0592_sail.py --output /tmp/linxisa-0592-sail
python3 tools/isa/export_linxisa_v0592_sail.py --check /tmp/linxisa-0592-sail
```

The release assets contain the specification and Sail archives, their SHA-256 checksums and a verification record. The exported Sail model retains the existing execution behavior for legacy encodings. The architecture decision leaves the execution policy for legacy binaries open.

## Platform validation

Qualification covers the specification, encodings and Sail package. Platform bring-up continues to use the v0.58 default profile. Compiler and emulator promotion, RTL execution parity, final Linux/rootfs pins and full-system qualification require separate evidence. The earlier release records the available system results and outstanding work. [System validation record](v0.59.1.md#system-validation-at-specification-publication)
