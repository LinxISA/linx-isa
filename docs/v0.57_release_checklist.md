## ⚠️ 潜在风险

1. **工具脚本兼容性**
   - `build_golden.py` 可能不支持新的 .opc 字段
   - 可能需要修改脚本以支持 DMA 指令组

2. **QEMU 模拟器**
   - 需要实现 CAS 的原子语义
   - 需要实现寄存器复用逻辑
   - 多线程场景下的原子性验证

3. **LLVM 编译器**
   - 需要识别 CAS 指令
   - 需要实现 CAS 选择算法（32-bit vs 48-bit）
   - 需要处理寄存器复用（可能需要插入 MOV）

4. **RTL 实现**
   - 原子执行单元需支持 CAS
   - 缓存一致性协议需支持 far 标志
