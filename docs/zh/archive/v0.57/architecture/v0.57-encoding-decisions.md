# 灵犀指令集 v0.57 编码决策

> 历史、非规范归档。不得将本页用于当前 ISA 或实现决策。

本文档记录 v0.57 的规范编码分配。未在此列出的编码继续由 v0.57
规范操作码目录定义。

## 稳定性规则

既有形式的字节编码、解码合法性和保留行为保持稳定，也不会恢复遗留兼容
拼写。活动源只接受规范 v0.57 拼写。

## TMA Function 窗口

以下所有行使用 TMA 块头模式：

`31..27=DataType`，`26..25=00`，`24..20=Function`，
`19..15=00010`，`14..0` 为固定块分割尾部。

mask 排除 `DataType`，包含 function 选择子和固定尾部：
`mask=0x07ffffff`。

| Function | 别名 | Match | 决策 |
|---:|---|---:|---|
| 0 | `BSTART.TLOAD` | `0x00011181` | 规范 |
| 1 | `BSTART.TSTORE` | `0x00111181` | 规范 |
| 2 | `BSTART.TMOV` | `0x00211181` | 规范 |
| 3 | `BSTART.TPREFETCH` | `0x00311181` | v0.57 新选择子 |
| 4 | `BSTART.MGATHER` | `0x00411181` | v0.57 新选择子 |
| 5 | `BSTART.MSCATTER` | `0x00511181` | v0.57 新选择子 |
| 6 | `BSTART.MGATHER.MASK` | `0x00611181` | v0.57 新选择子 |
| 7 | `BSTART.MSCATTER.MASK` | `0x00711181` | v0.57 新选择子 |
| 8 | `BSTART.MGATHER.CAS` | `0x00811181` | v0.57 新选择子 |
| 9..31 | 保留 | — | 非法指令 |

`BSTART.TPREFETCH` 明确放在 `TLOAD`、`TSTORE`、`TMOV` 后的相邻 function
槽位，而不是远端扩展窗口。

## `TPREFETCH` 编码合约

`BSTART.TPREFETCH` 编码为 TMA `Function=3`：

- mask：`0x07ffffff`
- match：`0x00311181`
- `DataType` 仍使用现有 5 位 TMA 数据类型字段。

架构上，`TPREFETCH` 是没有目的端的 `TLOAD`。它使用与 `TLOAD` 相同的
地址生成和内存合约，但不得分配或写入 tile 目的端。

## PTO 选择子清单规则

完整 111 个 PTO tile 操作的精确映射以下列文件为准：

`isa/v0.57/state/pto_encoding_map.json`

源工作簿被规范化为 `pto_ops.json`，正常构建不会读取工作簿。工作簿行号
不分配编码。已有 TEPL 选择子保持不变；新选择子只使用
`0x02B..0x048`、`0x080..0x08B`、`0x0C0..0x0C8` 和
`0x0E0..0x0E3`。其余 10 位取值均保留。

## CUBE Function 映射

PTO 矩阵操作使用继承的 CUBE family 和具名别名：

| Function | 规范别名 | PTO 拼写 |
|---:|---|---|
| 0 | `BSTART.TMATMUL` | `TMATMUL` |
| 1 | `BSTART.TMATMUL.BIAS` | `TMATMUL_BIAS` |
| 2 | `BSTART.TMATMUL.ACC` | `TMATMUL_ACC` |
| 4 | `BSTART.TMATMULMX` | `TMATMUL_MX` |
| 16 | `BSTART.TGEMV` | `TGEMV` |
| 17 | `BSTART.TGEMV.BIAS` | `TGEMV_BIAS` |
| 18 | `BSTART.TGEMV.ACC` | `TGEMV_ACC` |
| 20 | `BSTART.TGEMVMX` | `TGEMV_MX` |

Function 5、6、21、22 还提供已文档化的微缩放 bias/accumulate 具名别名。
通用 `BSTART.CUBE Function, DataType` 形式保持合法；
没有具名别名的 function 值因此只保留通用解码。

## 标量编码证据

v0.57 增加 LinxISA/linx-isa#139 中的下列 32 位编码，同时保持原有 48 位
`HL.CAS*` 形式不变：

| 形式 | Mask | Match | v0.57 决策 |
|---|---:|---:|---|
| `CASB` | `0x0000707f` | `0x0000001b` | 32 位本地 byte compare-and-swap |
| `CASH` | `0x0000707f` | `0x0000101b` | 32 位本地 halfword compare-and-swap |
| `CASW` | `0x0000707f` | `0x0000201b` | 32 位本地 word compare-and-swap |
| `CASD` | `0x0000707f` | `0x0000301b` | 32 位本地 doubleword compare-and-swap |
| `DMA` | `0xfe007fff` | `0x0000700b` | 继承的固定 64 字节复制操作的 32 位编码 |

对于 `DMA`，`SrcL` 仍是源地址，`SrcR` 仍是目的地址。PR #139 未分配
控制字格式；其中临时使用的“控制参数”措辞不具备规范效力。

## 拒绝规则

汇编器、解码器和测试必须拒绝：

- 通用混合 TMA 源形式，
- 未分配 TMA function，
- v0.57 之前来源中的已退休兼容拼写，
- 未出现在冻结 v0.57 清单中的 PTO 选择子数字。
