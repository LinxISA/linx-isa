# 0.59.1 静态手册审阅记录

## 本次逐页修订

0.59.1 指令详情使用与发布目录、锁定的 PTO 定义或 Linx Sail 相符的中文正文。原页的操作说明、示例和图在含义一致时沿用。修订后的中文稿可以从详情页下载，每个页面对应的编码标识和语义来源记录在包内的 `detail-audit.json` 中。

| 指令 | 核对要点 |
| --- | --- |
| HL.CCAT、HL.CCATW | 先拼接再逻辑右移，低半部先写 Dst0。字形式分别符号扩展两个结果，移位量为 64 至 127 时两个结果为零。 |
| DIV、MULUW | 除数为零时商为零。MULUW 将乘积低 32 位符号扩展到 64 位。 |
| FADD、FCVT | 普通标量浮点加法只接受 FP64 和 FP32。浮点转换另有 FP16、E4M3 的类型编码。 |
| TMATMUL.ACC | C 是显式累加源，D 是新分配的输出。 |
| V.SH.BRG、V.SW.BRG、V.SD.BRG | 目录汇编把元素宽度计入寄存器索引的移位量，发布 Sail 只使用 shamt。详情页分别列出两个表达式，本版资料尚未统一这一地址计算。 |

以下记录来自较早版本的静态手册审阅，说明当时发现的问题和处理方式。

## 审阅范围

独立审阅者按芯片实现者的阅读顺序，从分类索引进入指令页，对照本地中文站原稿、0.59.1 目录、发布版模型和实际生成的 HTML。重点抽查了 C.MOVR、DC.IALL、MGATHER、矩阵累加、谓词映射、系统寄存器，以及从指令示例跳到公共伪代码的离线路径。全站检查另按编码形式、来源和本地链接逐项运行。

## 审阅发现与修改

| 项目 | 发现 | 修改 |
| --- | --- | --- |
| MGATHER | 中文原页允许 u16 索引；普通聚集的循环也容易被误读为原子变体的操作。 | 在原文前列出本版索引类型、字节位移、基址字段、可选范围描述符和预检边界。原子和掩码变体另注明差异。 |
| Tile 状态 | 旧中文页面使用隐式 ACC，且没有区分本地、共享绑定的大小编码。 | 在状态页分别列出 B.IOT、B.IOS 的大小范围和显式累加源 C、目标 D。保留旧页供对照。 |
| 谓词 | “一位对应一个元素”会让读者忽略元素宽度。 | 在 PRED 页说明发布模型中由两个 32 位通道承载一个 64 位元素的路径，并给出实例入口。 |
| 系统寄存器 | 一个章节与寄存器索引曾共用同一 URL，导致索引表被覆盖。 | 章节和索引使用独立地址，按作用域、名称和地址或低位索引核对全部 100 条记录。 |
| B.ASSEMBLE | 一处增补说明省略了丢弃组的前提，容易误解为所有形式都不读 GPR。 | 单列前置绑定 PEMode=000 的处理，再说明参与组如何读取 GPR、计算并记录偏移。 |
| 图与文字 | 仅有绘图草稿不足以说明最终图片正确；泛化的“通道”也容易与 PE 或向量通道混淆。 | 图旁以有效索引位置说明地址和结果，保存最终位图的摘要、绘图输入和审阅记录。 |

## 正文编辑与复核

中文站原稿按发布标签读取。使用 humanizer-zh 的技术文档规则校读正文，保留条件、取值范围、否定和操作顺序。已有说明清楚的段落沿用原文。例如 `C.MOVR` 的首句不需要扩写。编辑记录按成品页面写入 `editorial-audit.json`，同时保存中文原稿供对照。[humanizer-zh，固定修订](https://github.com/op7418/humanizer-zh/blob/f4518a8eab97b8bfebc66a89d34320a89bef6930/SKILL.md)

从仓库根目录运行 `make -C docs/architecture/isa-manual html-reference check-html-reference`，可重建页面并检查编码、原文、目录、架构状态、图和离线资源。编码和资料覆盖检查的范围见发行说明；硬件符合性仍须在对应实现上验证。
