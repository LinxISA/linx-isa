# LinxISA 0.59.1 规范发布

`v0.59.1` 发布 ISA 规范、二进制编码和组装后的 Sail 模型。芯片设计查阅本版时应显式选择 `v0.59`。整机 bring-up 的默认 profile 仍为 `v0.58`。[发布清单](https://github.com/LinxISA/linx-isa/blob/v0.59.1/isa/v0.59/release_manifest.json) · [英文发行说明](https://github.com/LinxISA/linx-isa/blob/v0.59.1/docs/releases/v0.59.1.md)

离线 HTML 手册共 1,584 页。解压后打开 `index.html`，即可按助记符、位编码和 Tile 操作查阅。[下载 0.59.1 HTML 手册](https://github.com/LinxISA/linx-isa/releases/download/v0.59.1/linxisa-0.59.1-html.zip)

## 规范范围

754 个目录助记符对应 1,499 个编码形式，包括 473 个普通标量形式、105 个命令形式、216 个 Linx 专有形式，以及 705 个带作用域的 64 位形式。119 个直接 Tile 操作通过命令中的选择器编码，单独计数。上游 PTO 标签为 `v0.59.1.0`，源提交为 `a89a53d48f5708328be609fe2e6296ac8bdb4bc2`。配置还导入了 100 项系统寄存器定义和 50 项 PTO 扩展编码空间保留记录。[上游锁文件](https://github.com/LinxISA/linx-isa/blob/v0.59.1/isa/v0.59/pto-spec.lock.json)

ELF 身份由版本 `0.59.1`、ABI `pto-isa-0.59.1-mode-function-v1` 和编码投影 SHA-256 `d90c881754d66f2cd26f6014d0b582cba88307e70123583d87fc59a918229c28` 确定。578 个公共形式保留固定位，`B.DATR.CMode` 和 `BSTART.TMOV.DataType` 的允许取值增加。705 个 scoped 形式与原有 194 个 64 位 Linx 形式的编码空间互不相交。

Sail 0.20.2 的验证包括从本版目录生成译码器、组装模型、解析、执行定向测试和生成 C 后端。scoped 接口描述请求、阻塞、故障、完成和退休；存储及排序效果由接入的平台提供。复现命令见英文发行说明。

| 范围 | 发布时的验证状态 |
| --- | --- |
| 编译器与模型 | 11 个 QEMU 套件检查了 ELF 的本版身份，71 个抽查形式通过执行和结果校验。数值及符号重定位两组 scoped 测试各在四个模型核对了 180 个载体和 1,440 字节结果。TSVC 诊断达到 122/151，原门槛为 148，仍需实现合法的无分支降级。[LLVM #182](https://github.com/LinxISA/llvm-project/pull/182) |
