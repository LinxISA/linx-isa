# LinxISA v0.57.0

LinxISA v0.57.0 是唯一活动的 LinxISA 版本。它将完整既有架构合约与
标量、tile、PTO、工具链、模拟器、Linux、RTL、模型、工作负载和文档更新
整合成统一稳定基线。

## 合约变更

- TMA `Function=3` 分配给 `BSTART.TPREFETCH`。
- `TPREFETCH` 与 `TLOAD` 使用相同的地址生成、内存异常、排序和可重启
  合约，但没有目的绑定、分配、队列 push、写回或目的依赖。
- TMA Function 4..8 分别分配给 `MGATHER`、`MSCATTER`、
  `MGATHER.MASK`、`MSCATTER.MASK` 和 `MGATHER.CAS`。
- 冻结的 PTO 清单对工作簿全部 111 行进行分类：97 个 TEPL、6 个 TMA、
  8 个 CUBE 编码归属；仅评审材料中的名称和拼写错误被拒绝。
- 为已文档化的矩阵和矩阵-向量 function 增加 CUBE 具名别名，同时保留
  通用 `BSTART.CUBE` 形式。
- 增加 32 位 `CASB/CASH/CASW/CASD` 和 `DMA` 编码。DMA 使用固定
  64 字节源地址到目的地址复制语义。

## 架构整合

v0.57 目录包含完整规范 ISA，不依赖另一套活动基线。架构页面已整合块执行、
SIMT 编译器、工作负载引擎、渲染、强化、特权、内存和调用返回合约；已退休
兼容拼写和遗留示例不再作为活动发布面。

## 提升状态

v0.57 的生成 ISA、编译器、模拟器、Linux、RTL、模型、工作负载和文档必须
与同一份机器可读目录和清单保持一致。
