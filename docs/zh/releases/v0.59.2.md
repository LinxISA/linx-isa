# LinxISA v0.59.2 规范发布说明

v0.59.2 在机器可读目录的 **1,499 个指令形式中标记了 193 个 obsolete 形式**。选择 `v0.59.2` 配置即可取得本版架构规范、编码和 Sail 模型。架构决策附有完整助记符清单和块入口的掩码、匹配值。[架构决策](../architecture/linx-two-level-block-obsolescence.md) · [发布目录](https://github.com/LinxISA/linx-isa/blob/v0.59.2/isa/v0.59.2/linxisa-v0.59.2.json)

| 架构状态 | 形式数 | 范围 |
| --- | ---: | --- |
| obsolete | 193 | 全部 184 个 `V.*`，MSEQ、MPAR、VSEQ、VPAR 的 8 个普通和压缩块入口，以及 `B.TEXT` |
| 沿用的 Linx 扩展 | 19 | `HL.BSTART.CALL` 及 48 位、64 位的 FP、STD、SYS 扩展块头 |
| 只预留编码 | 4 | `DMA.FREE.L`、`DMA.FREE.S`、`MCOPY.DL`、`MCOPY.DS`。执行须在读取操作数或产生架构效果前拒绝 |
| 与 PTO 共有 | 1,283 | 578 个基础标量及块命令形式、705 个显式访存作用域封装 |

这 193 个形式落在 PTO 的 10 条预留记录中，整个匹配空间继续预留。119 个 Tile 操作单独计数，其中包含 32 个 Tile VEC 操作。本版沿用 0.59.1 的 PTO 锁定提交、指令编码和 ELF ABI。工具应读取 Linx 规范版本来区分两版目录；ELF 标识表明程序使用的共享编码 ABI。[PTO 锁定记录](https://github.com/LinxISA/linx-isa/blob/v0.59.2/isa/v0.59/pto-spec.lock.json)

216 个 Linx 独有形式均带有 `architecture_status.state` 字段，其中 193 项取值为 `obsolete`。

## 重建与核验

在发布标签的检出目录中运行以下命令。

```sh
python3 tools/isa/select_linxisa_profile.py --profile v0.59.2 --require-release-qualified
python3 tools/isa/build_golden.py --profile v0.59.2 --check
python3 tools/isa/validate_spec.py --profile v0.59.2
python3 tools/isa/export_linxisa_v0592_sail.py --output /tmp/linxisa-0592-sail
python3 tools/isa/export_linxisa_v0592_sail.py --check /tmp/linxisa-0592-sail
```

发行附件提供规范包、Sail 模型包、SHA-256 校验和与验证记录。导出的 Sail 保留旧编码的现有执行行为。旧二进制在未来架构目标上的执行策略仍待单独裁决。

## 系统验证范围

本次验证覆盖规范、编码和 Sail 包。平台 bring-up 默认配置仍为 v0.58。编译器与模拟器升级、RTL 执行一致性、最终 Linux/rootfs 组件组合及完整系统验证仍需各自的证据。已取得的系统结果与待完成事项见上一版发行记录。[系统验证记录](v0.59.1.md)
