# LinxISA v0.58.1

LinxISA v0.58.1 是 PTO ISA 0.58 迁移的可复现修正版。它补齐历史
`v0.58` 标签缺失的组件一致性和发布证据，但不移动或删除该历史标签。

## 契约身份

- LinxISA profile：`v0.58`
- PTO release：`0.58.1`
- 编码 ABI：`pto-isa-0.58.1-mode-function-v1`
- 编码投影 SHA-256：
  `89b872d6eaf0252200bc9349d49b9346e2a69d894cdcc2dcd0fd71911c1e0b8c`
- PTO 目录：474 条 scalar form、74 条 command form 和 32 个 extension
  encoding reservation
- PTO 公开 Tile 操作目录：109 条
- Shared Tile 绑定：32-bit `B.IOS` 和绝对索引 `S0..S255`
- Per-PE TSize：编码 `1..7` 对应 128 B 到 8 KiB

发布链会拒绝旧指令拼写和混合版本身份，不会默认接受 v0.57/v0.58
混用对象。

公共子集新增 `B.FPATR`、融合 `BSTART.CALL`、融合 `BSTART.ICALL` 和
`L.BSTOP`，删除四个旧 FP/STD CALL/ICALL 拼写。Linx-only 两级指令只有在
PTO reservation 目录完整覆盖其编码时才保留。

## 修正的集成面

- LLVM、PTOAS、QEMU、Linux、glibc 和 musl 使用字节级一致的
  `.note.pto.isa` 身份，并对缺失、旧版、畸形、冲突和混合身份 fail closed。
- Linx-TileOP-API 和内嵌维护的 SuperNPU workload 使用当前 Shared TMOV、
  allocation-mask 和 per-PE TSize 契约。
- 架构模型、pyCircuit 和 LinxCore 消费同一份 v0.58 生成目录。
- LinxCoreModel 候选仅作为未合并 PR 审查，不宣称为已发布组件。

## 可复现性

不可变的 `v0.58.1` 标签是规范架构权威，它固定生成的 ISA 手册、公开目录、
PTO 身份和 release manifest。修正后的 superproject 集成位于 `main` 的后续
提交中，其 component lock 和 gate 证据记录所有叶仓的精确合入提交；不会移动
该标签来指向这些后续提交。如果发布修正后的集成，必须使用新的 patch 版本。

`PTO-ISA/SuperNPUBench` 仅保留为 issue 跟踪面；本发布不在该独立仓库推送
代码、创建标签或发布 Release。受维护的 workload 证据来自
`workloads/pto_kernels/benchmarks/supernpu`。
