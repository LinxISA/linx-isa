# TMATMUL.ACC

## 说明

将 M×K 的矩阵 A 与 K×N 的矩阵 B 相乘，再加上显式输入 Tile C 的对应元素。把结果写入新分配的目标 Tile D。

## 操作数

| 操作数 | 用途 |
| --- | --- |
| `destination0` | D |
| `source0` | C（累加源） |
| `source1` | A |
| `source2` | B |

C 是本地累加源，D 是独立的本地输出。解码时，C 的相对编号必须与零扩展的 DstTile 不同。

## 执行方式

本地 A 采用 CUBE_M16 或 CUBE_M32 布局，本地 B 采用 CUBE_N8。发布版还允许以已发布的共享 B 替换右侧输入，或同时使用共享 A 和共享 B。块头使用 `BSTART.TMATMUL.ACC AType`，并且必须有一条 B.FPATR 来指定后处理。数值运算先形成累加值，再按块头配置处理并发布 D。

## 示例

看输出中的一个位置。若 A 的一行为 [2, 3]，B 的对应列为 [4, 5]，点积为 2×4 + 3×5 = 23。若 C 的对应元素为 7，后处理前的累加值为 30。
