# TGEMV

## 说明

将 1×K 的行向量 A 与 K×N 的矩阵 B 相乘。把结果写入新分配的目标 Tile D。

## 操作数

| 操作数 | 用途 |
| --- | --- |
| `destination0` | D |
| `source0` | A（行向量） |
| `source1` | B（矩阵） |

A、B 提供乘法输入，D 接收输出。

## 执行方式

M 固定为 1，只能使用本地输入；TransA 和 TransB 均为零。块头使用 `BSTART.TGEMV AType`，并且必须有一条 B.FPATR 来指定后处理。数值运算先形成累加值，再按块头配置处理并发布 D。

## 示例

看输出中的一个位置。若 A 的一行为 [2, 3]，B 的对应列为 [4, 5]，点积为 2×4 + 3×5 = 23。这个位置在后处理前的累加值为 23。
