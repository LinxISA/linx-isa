# TMATMUL.BIAS

## 说明

将 M×K 的矩阵 A 与 K×N 的矩阵 B 相乘，再给每一列加上该列的偏置。把结果写入新分配的目标 Tile D。

## 操作数

| 操作数 | 用途 |
| --- | --- |
| `destination0` | D |
| `source0` | A |
| `source1` | B |
| `source2` | 偏置 |

偏置来自显式的本地 Tile，形状为 1×N，布局为 CUBE_N8。

## 执行方式

本地 A 采用 CUBE_M16 或 CUBE_M32 布局，本地 B 采用 CUBE_N8。发布版还允许以已发布的共享 B 替换右侧输入，或同时使用共享 A 和共享 B。块头使用 `BSTART.TMATMUL.BIAS AType`，并且必须有一条 B.FPATR 来指定后处理。数值运算先形成累加值，再按块头配置处理并发布 D。

## 示例

看输出中的一个位置。若 A 的一行为 [2, 3]，B 的对应列为 [4, 5]，点积为 2×4 + 3×5 = 23。若该列偏置为 7，后处理前的累加值为 30。
