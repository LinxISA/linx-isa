# TGEMV.ACC

## 说明

将 1×K 的行向量 A 与 K×N 的矩阵 B 相乘，再加上显式输入 Tile C 的对应元素。把结果写入新分配的目标 Tile D。

## 操作数

| 操作数 | 用途 |
| --- | --- |
| `destination0` | D |
| `source0` | C（累加源） |
| `source1` | A（行向量） |
| `source2` | B（矩阵） |

C 是本地累加源，D 是独立的本地输出。解码时，C 的相对编号必须与零扩展的 DstTile 不同。

## 执行方式

M 固定为 1，只能使用本地输入；TransA 和 TransB 均为零。块头使用 `BSTART.TGEMV.ACC AType`，并且必须有一条 B.FPATR 来指定后处理。数值运算先形成累加值，再按块头配置处理并发布 D。

## 示例

看输出中的一个位置。若 A 的一行为 [2, 3]，B 的对应列为 [4, 5]，点积为 2×4 + 3×5 = 23。若 C 的对应元素为 7，后处理前的累加值为 30。
