# TLSU 数据搬运块

## 功能概述

TLSU（Tile Load/Store Unit）是 v0.58 在内存子系统与 Tile 寄存器之间的数据搬运接口，执行 PTO 0.58 目录分配的 TLOAD/TSTORE/TMOV/TPREFETCH、gather/scatter、掩码、CAS 和 GMOV 操作。

## 核心能力

| 功能 | 说明 |
|------|--------|
| **多维数据搬移** | TLSU 支持 v0.58 目录定义的跨步、gather/scatter、掩码、原子 CAS、集体 GMOV 与 Tile 寄存器搬移。 |
| **异步并行执行** | TLSU 使用独立硬件执行引擎，并遵守 v0.58 内存模型记录的架构顺序规则。 |
| **零开销数据管理** | 通过专用硬件实现数据传输的优化管理：<br>1.自动地址生成：消除软件地址计算的额外开销<br>2.突发传输优化：最大化内存带宽利用率<br>3.数据格式转换：支持计算格式与存储格式的透明转换 |

## 架构定位

TLSU 位于内存控制器与计算单元之间：
```
内存子系统 → TLSU → Tile寄存器阵列 → 计算单元
```
该设计实现了存储访问与计算执行的解耦，允许计算单元专注于算术逻辑运算，而数据供给由专用硬件保障。

与计算单元的接口

- 数据供给接口：向计算单元提供输入数据加载服务
- 结果回收接口：接收计算单元的输出数据并写回内存
- 寄存器间传输：支持Tile寄存器阵列内部的数据重组和复制

## 块类型特征

- 数据搬运块**仅支持Fall跳转方式**
- 数据搬运块允许访问 全局寄存器GGPR，Tile寄存器，内存。
- 数据搬运块一个块最多允许读8个Tile寄存器，写4个tile寄存器。
- 数据搬运块无块体，**不允许使用B.TEXT指令**
