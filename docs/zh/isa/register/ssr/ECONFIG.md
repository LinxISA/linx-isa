# ECONFIG

`ECONFIG_ACRn` 是 64 位可读写异常/中断配置寄存器，每硬件线程、每管理 ACR 独立。

## 字段布局

| 字段 | 位 | 含义 |
| --- | ---: | --- |
| `E` | `0` | 外部中断使能 |
| `T` | `1` | 定时器中断使能 |
| `S` | `2` | 软件中断使能 |
| `A` | `3` | `ASSERT` 指令异常使能 |
| 保留 | `31:4` | 写入必须为零，读出为零 |
| `V` | 位 32 | VECTOR 首次使用异常使能 |
| `C` | 位 33 | CUBE 首次使用异常使能 |
| 保留 | `63:34` | 写入必须为零，读出为零 |

复位值：`0x0000000300000008`。

## 首次使用控制

在当前未发布的 v0.58 主线契约中，`ECONFIG_ACR1.V/C` 控制 ACR2 任务的首次使用异常：

- `V=1`：受控 VECTOR 块头在执行前陷入；
- `C=1`：受控 CUBE 块头在执行前陷入；
- 对应位为 `0`：关闭该类首次使用异常。

处理一种扩展时只清除对应位。返回 ACR2 之前，软件必须按下一个任务重新写入 V/C；不能用复位值替代逐任务配置。

## 地址空间

| 管理 ACR | 寄存器 | SSR ID |
| --- | --- | --- |
| ACR0 | `ECONFIG_ACR0` | `0x0F07` |
| ACR1 | `ECONFIG_ACR1` | `0x1F07` |
| ACR2 | `ECONFIG_ACR2` | `0x2F07` |
| ACRn | `ECONFIG_ACRn` | `0xnF07` |
