# PT

## 说明

**Persistent Tile（持久化 Tile 寄存器）**

Persistent Tile（简称 PT）是一种显式管理、跨块持久化、不会被普通 Tile 重命名机制影响的核内局部存储区域。它用于稳定驻留需要跨多个计算块共享的数据（如共享缓冲区、参数块、查找表等），解决普通 Tile 因寄存器重命名导致的瞬态性问题。

## 主要属性

- **跨块持久化**：PT 被分配后可跨不同块存活，申请的块及后续块指令均可读写该寄存器，直至被显式释放。
- **不受 Tile 重命名影响**：普通 Tile 的重命名机制不会覆盖 PT 区域，PT 的地址空间独立管理。
- **地址空间从 0 开始**：PT 的地址空间从 0 开始编址，最大不超过线程级 Tile 容量上限。
- **计入 Tile 容量预算**：PT 的容量计入线程的总体 Tile 容量预算，而非额外分配独立状态。即 PT 与普通 Tile 共享同一容量池。

## 分配与释放

PT 通过 B.IOT 指令进行分配和释放：

### 分配

```asm
    B.IOT [xx], ->PT<Size>
```

- **xx**：保留字段（当前未使用，填 0）。
- **Size**：PT 的空间大小，有效范围 256B ~ 256KB 且必须是 256B 的 2 次幂倍数。

当 PT 被成功分配后，其状态标记为有效（valid），后续块指令即可通过本地寻址方式访问该 PT。

### 释放

```asm
    B.IOT [xx], ->PT.FREE
```

释放后 PT 状态标记为无效，对应容量归还给 Tile 容量池。

## 访问方式

PT 采用 `.local` 形式的本地寻址访问，与普通 Tile 的 `.local` 访问类似，但使用独立的 `PT` 作为基址标识：

```asm
    l.load.local  [PT, 0x40], ->p           // 从 PT 偏移 0x40 处加载到标量寄存器
    v.store.local vt#1, [PT, lc0<<2, 0x100] // 将向量数据存储到 PT
```

## 使用约束

1. **先分配后访问**：PT 未被分配前，块指令不允许读取该寄存器，否则硬件报异常。
2. **释放后不可访问**：PT 被释放后，块指令不允许读取该寄存器，否则硬件报异常。
3. **容量限制**：PT 的容量与其他普通 Tile 共享线程级总容量预算，分配时需确保剩余容量充足。
4. **显式管理**：PT 不会自动释放，必须由软件通过 `B.IOT [xx], ->PT.FREE` 显式释放。
