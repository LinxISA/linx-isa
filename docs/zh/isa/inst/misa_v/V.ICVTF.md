# V.ICVTF

## 说明

逐活动元素把 `SrcL` 中由 `SrcType` 指定的整数转换为 `DstType` 指定的浮点格式。整数位宽和符号性由源类型编码决定；转换使用当前浮点舍入模式，并累计浮点异常标志。64 位源或目的元素由相邻的两个 32 位通道承载。

本指令只有一个源寄存器，不读取第二个源寄存器，也没有编码 `rm` 或 `sat` 操作数。源整数类型或目的浮点类型不受发布模型支持时，指令触发非法指令异常。P 掩码为 0 的元素结果未指定。

## 汇编语法

```asm
v.icvtf.{st2dt} SrcL, ->Dst
```

## 例子

`v.icvtf.u82e5m2 vt#1.ub, ->vt.b` 把 `vt#1` 中的无符号 8 位整数转换为 E5M2 浮点元素。
