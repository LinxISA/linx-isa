# V.CMP.AND

## 说明

逐活动通道执行布尔与比较。先分别判断 `SrcL` 和 `SrcR` 的 32 位通道值是否非零，再对两个真值执行 AND；两者都非零时写入 1，否则写入 0。这不是先做按位与再判断结果是否非零。

P 掩码为 0 的通道结果未指定，软件不能假定它被写成 0 或保留原值。

## 汇编语法

```asm
v.cmp.and SrcL, SrcR, ->Dst
```

## 编码格式

![V.CMP.AND](../../../figs/bitfield/svg/Instruction_64bit/V.CMP.AND.svg)

## 例子

活动通道的 `SrcL = 1`、`SrcR = 2` 时，两个输入都非零，因此结果为 1。按位计算 `1 & 2` 虽然得到 0，但那不是本指令的语义。
