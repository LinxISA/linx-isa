# V.REV

## 说明

v0.59.1 发布 Sail 对每个活动的 32 位通道执行完整的字节序反转：原字节 3、2、1、0 依次成为结果字节 0、1、2、3。当前发布模型忽略编码中的 `immr` 和 `imml` 字段，因此汇编中的 `M`、`N` 不会改变发布 Sail 的执行结果。

P 掩码为 0 的通道结果未指定。

## 汇编语法

```asm
v.rev SrcL, M, N, ->Dst
```
