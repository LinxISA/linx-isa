# V.ICVT

## 说明

逐活动元素在整数格式之间转换 `SrcL`。v0.59.1 发布 Sail 支持 64、32、16 和 8 位的有符号或无符号整数：变窄时保留低位，变宽时按源类型做符号扩展或零扩展，位宽不变时保留原位模式。64 位元素由相邻的两个 32 位通道承载。

本指令只有一个源寄存器，不读取第二个源寄存器，也没有编码 `rm` 或 `sat` 操作数。发布 Sail 未支持的类型编码会触发非法指令异常。P 掩码为 0 的元素结果未指定。

## 汇编语法

```asm
v.icvt.{st2dt} SrcL, ->Dst
```

## 例子

有符号 8 位值 `0x80` 转为有符号 16 位时得到 `0xff80`；无符号 8 位值 `0x80` 转为无符号 16 位时得到 `0x0080`。

`v.icvt.u82u16 vt#1.ub, ->vt.h` 只读取 `vt#1` 一个源寄存器。
