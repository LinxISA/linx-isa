# CASB - 原子比较交换字节

## 指令格式

```
casb<.{aq, rl, f, aqrl, aqf, rlf, aqrlf}> [SrcL], SrcR, {t, u, Rd}, ->{t, u, Rd}
```

## 指令说明

CASB（Compare-And-Swap Byte）指令原子地比较内存中的字节值与期望值，如果相等则用新值替换。无论比较是否成功，都返回内存中的旧值。

**⚠️ 重要**：目的寄存器既作为输入（新值），也作为输出（旧值），输入值会被覆盖。

## 编码格式

```
位段: 31..28 | 27 | 26 | 25 | 24..20 | 19..15 | 14..12 | 11..7  | 6..4 | 3..1 | 0
     ────────────────────────────────────────────────────────────────────────────
     0000   | f  | a  | r  | SrcR   | SrcL   | 111    | RegDst | 000  | 101  | 1
     CASB   |far | aq | rl | 比较值 | 地址   | CAS    | 复用   |原子组|      |
```

**编码详情**：
- 31..28 = 4'b0000（字节宽度）
- 27 = far（远程缓存标志）
- 26 = aq（acquire 内存序）
- 25 = rl（release 内存序）
- 24..20 = SrcR（期望值寄存器，5 bits）
- 19..15 = SrcL（地址寄存器，5 bits）
- 14..12 = 3'b111（CAS 子操作码）
- 11..7 = RegDst（输入/输出寄存器，5 bits）
- 6..4 = 3'b000, 3..1 = 3'b101, 0 = 1（原子指令组）

## 操作数

| 操作数 | 方向 | 说明 |
|--------|------|------|
| **[SrcL]** | 输入 | 内存地址（字节对齐） |
| **SrcR** | 输入 | 期望值（expected value） |
| **{t, u, Rd}** | 输入 | 交换值（new value） |
| **->{t, u, Rd}** | 输出 | 内存旧值（old value）⚠️ 覆盖输入 |

## 伪代码

```c
integer m = UInt(SrcL);          // 地址
integer n = UInt(SrcR);          // 期望值
integer d = UInt(RegDst);        // 交换值（输入）

Atomic {
    bits(8) old_value = Mem[m, 8];
    bits(8) expected = n[7:0];
    bits(8) new_value = d[7:0];
    
    if (old_value == expected) {
        Mem[m, 8] = new_value;   // 比较成功，写入新值
    }
    
    R[RegDst, 64] = ZeroExtend(old_value, 64);  // 总是返回旧值
}
```

## 汇编示例

### 基本用法

```asm
# 原子比较交换
casb [x5], x6, x7, ->x7
# 如果 [x5] == x6，则 [x5] = x7
# x7 = 旧值 (输入被覆盖)
```

### 保留交换值

```asm
# 需要保留交换值时
mov x8, x7                  # 先备份
casb [x5], x6, x7, ->x7
# x7 = 旧值，x8 = 交换值（保留）
```

### 内存序标志

```asm
# Acquire 语义
casb.aq [x10], x11, x12, ->x12

# Release 语义  
casb.rl [x1], x2, x3, ->x3

# 完整内存屏障
casb.aqrl [x15], x16, x17, ->x17

# 远程缓存访问
casb.f [x20], x21, x22, ->x22

# 组合标志
casb.aqrlf [x25], x26, x27, ->x27
```

### 输出到队列寄存器

```asm
# 输出到 t 队列
casb [x5], x6, t, ->t

# 输出到 u 队列
casb [x10], x11, u, ->u
```

## 使用场景

### 1. 自旋锁实现

```asm
# 获取锁
lock_acquire:
    li x6, 0                    # 期望值：未锁定
    li x7, 1                    # 新值：锁定
    casb [x5], x6, x7, ->x7     # 尝试获取锁
    bnez x7, lock_acquire       # 如果旧值!=0，重试
    # 锁获取成功
```

### 2. 无锁队列

```asm
# 原子更新头指针
enqueue_retry:
    lb x6, [x5]                 # 读取当前头指针
    addi x7, x6, 1              # 计算新头指针
    casb [x5], x6, x7, ->x7     # 原子更新
    bne x7, x6, enqueue_retry   # CAS 失败，重试
```

### 3. 引用计数

```asm
# 原子增加引用计数
incref_loop:
    lb x6, [x5]                 # 读取当前计数
    addi x7, x6, 1              # +1
    casb [x5], x6, x7, ->x7
    bne x7, x6, incref_loop     # 重试直到成功
```

## 内存序说明

| 标志 | 含义 | 使用场景 |
|------|------|---------|
| 无 | 无内存序约束 | 性能优先，单线程或已有同步 |
| `.aq` | Acquire 语义 | 获取锁后，禁止后续内存操作提前 |
| `.rl` | Release 语义 | 释放锁前，禁止之前内存操作延后 |
| `.aqrl` | 完整内存屏障 | 强同步场景，CAS 前后都有约束 |
| `.f` | 远程缓存 | NUMA 系统，跨 socket 原子操作 |

## 注意事项

1. **寄存器覆盖**：目的寄存器的输入值会被覆盖，如需保留请先 MOV
2. **字节对齐**：地址无需对齐，但对齐访问性能更好
3. **零扩展**：旧值以零扩展方式写入 64-bit 寄存器
4. **原子性保证**：整个 read-compare-write 序列是原子的
5. **ABA 问题**：CAS 无法检测 A→B→A 的变化，需要版本号机制

## 性能特征

- **延迟**：约 20-50 cycles（取决于缓存命中）
- **吞吐**：每个原子执行单元每周期 1 条
- **代码大小**：4 字节

## 与 48-bit HL.CASB 对比

| 特性 | CASB (32-bit) | HL.CASB (48-bit) |
|------|--------------|------------------|
| 指令长度 | 4 字节 | 6 字节 |
| 寄存器 | 3 个（RegDst 复用） | 4 个（完全独立） |
| 交换值 | 被覆盖 | 保留 |
| 汇编 | `casb [x5], x6, x7, ->x7` | `hl.casb [x5], x6, x7, ->x8` |

**选择建议**：
- 高频原子操作 → CASB（更短）
- 需保留交换值 → HL.CASB
- 寄存器压力大 → HL.CASB

## 相关指令

- **CASH** - 原子比较交换半字（16-bit）
- **CASW** - 原子比较交换字（32-bit）
- **CASD** - 原子比较交换双字（64-bit）
- **SWAPB** - 原子交换字节（无比较）
- **HL.CASB** - 48-bit 版本（独立寄存器）
