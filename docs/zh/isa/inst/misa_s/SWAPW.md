# SWAPW

## 说明

原子交换·字（*Swap Word*）

`SWAPW` 从 `SrcL` 指定的地址原子读取一个 32 位字，把 `SrcR` 的低 32 位写回同一地址，并将读出的旧字**符号扩展到 64 位**后写入目的寄存器。

## 汇编语法

```asm
swapw<.{aq, rl, f, aqrl, aqf, rlf, aqrlf}> [SrcL], SrcR, ->{t, u, Rd}
```

## 操作数

| 操作数 | 作用 |
| --- | --- |
| `SrcL` | 4 字节对齐的原子访问地址 |
| `SrcR` | 新值；只使用低 32 位 |
| `RegDst` | 旧值，按 32 位有符号数扩展到 64 位 |

`.aq` 与 `.rl` 选择 acquire、release 或 acquire-release 排序；`.f` 是路由提示，在参考配置中不改变地址或结果。源和目的均使用 Reg5 选择器，可命名 GPR、T/U 临时来源以及 T/U 队列目的。

## 执行方式

执行前先对同一 4 字节范围完成读、写预检，并要求两次访问得到相同的转换后地址。预检全部通过后，旧字和新字的交换作为一次原子事件发生。失败时不写内存、不发布目的、不记录原子事件，也不推进 TPC。

完成的写入若与本地 64 字节保留粒度重叠，会使该保留失效。

## 示例

假设 a0 指向的字为 `0x80000001`，a1 为 `7`。

```asm
swapw [a0], a1, ->a2
```

执行后，内存字变为 `0x00000007`，a2 得到 `0xffffffff80000001`。这里的返回值是符号扩展结果，不是 `0x0000000080000001`。

## 约束

地址必须按 4 字节对齐，否则引发数据对齐故障。本指令只允许在系统块中执行。
