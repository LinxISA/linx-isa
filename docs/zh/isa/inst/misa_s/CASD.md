# CASD - 原子比较交换双字

## 指令格式

```
casd<.{aq, rl, f, aqrl, aqf, rlf, aqrlf}> [SrcL], SrcR, {t, u, Rd}, ->{t, u, Rd}
```

## 指令说明

CASD（Compare-And-Swap Doubleword）指令原子地比较内存中的双字（64-bit）值与期望值，如果相等则用新值替换。无论比较是否成功，都返回内存中的旧值。

**⚠️ 重要**：目的寄存器既作为输入（新值），也作为输出（旧值），输入值会被覆盖。

## 编码格式

```
位段: 31..28 | 27 | 26 | 25 | 24..20 | 19..15 | 14..12 | 11..7  | 6..4 | 3..1 | 0
     ────────────────────────────────────────────────────────────────────────────
     0011   | f  | a  | r  | SrcR   | SrcL   | 111    | RegDst | 000  | 101  | 1
     CASD   |far | aq | rl | 比较值 | 地址   | CAS    | 复用   |原子组|      |
```

**与 CASB 的区别**：
- 31..28 = 4'b0011（双字宽度，CASB 为 0000）
- 操作 64-bit 数据（CASB 操作 8-bit）

## 汇编示例

```asm
# 基本用法
casd [x5], x6, x7, ->x7

# 带内存序
casd.aq [x10], x11, x12, ->x12
casd.aqrl [x1], x2, x3, ->x3
```

## 伪代码

```c
Atomic {
    bits(64) old_value = Mem[SrcL, 64];
    if (old_value == SrcR[63:0]) {
        Mem[SrcL, 64] = RegDst[63:0];
    }
    RegDst = old_value;  // 无需扩展，已是 64-bit
}
```

## 使用场景

CASD 适用于：
- 64-bit 指针的原子更新（64-bit 地址空间）
- 大整数计数器
- 带版本号的指针（指针 + 版本号解决 ABA 问题）

## 注意事项

1. **对齐要求**：地址应 8-byte 对齐（性能最佳）
2. **无零扩展**：旧值直接写入 64-bit 寄存器，无需扩展
3. 其他特性与 CASB 相同，详见 [CASB 文档](CASB.md)
