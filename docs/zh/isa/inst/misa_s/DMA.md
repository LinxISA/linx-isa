# DMA - 直接内存访问（占位）

## 指令格式

```
dma SrcL, SrcR
```

## 指令说明

DMA（Direct Memory Access）指令用于直接内存访问操作。

**⚠️ 注意**：这是 v0.57.0 的**占位指令**，具体语义和功能尚未最终确定。

## 编码格式

```
位段: 31..28 | 27 | 26 | 25 | 24..20 | 19..15 | 14..12 | 11..7  | 6..4 | 3..1 | 0
     ────────────────────────────────────────────────────────────────────────────
     0000   | 0  | 0  | 0  | SrcR   | SrcL   | 000    | 00000  | 001  | 101  | 1
     全0    |    预留      | 源寄存器2 | 源寄存器1 | DMA    | 无输出 | DMA组 |      |
```

## 状态

- **版本**：v0.57.0
- **状态**：占位，待定义
- **预计完善**：v0.57.x 或 v0.58.0
