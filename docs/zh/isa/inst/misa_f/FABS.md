# FABS

## 说明

清除浮点操作数的符号位，其余有效位原样保留，将结果写入目的寄存器。

## 汇编语法

```asm
fabs.{T} SrcL, ->{t, u, Rd}
```

## 数据类型

SrcType 为 0 时读取 FP64，为 1 时读取低 32 位 FP32（载体高位补零）。编码 2 和 3 保留，执行时在读取源寄存器之前触发非法指令异常。

## 编码格式

![FABS](../../../figs/bitfield/svg/Instruction_32bit/FABS.svg)

## 执行方式

此操作只修改符号位，保留原有数值异常标志。

## 示例

输入为 −0.0，结果为 +0.0。
