# FGE

## 说明

比较两个浮点数。若左源大于或等于右源，写入 64 位整数 1，否则写入 0。

## 汇编语法

```asm
fge.{T} SrcL, SrcR, ->{t, u, Rd}
```

## 数据类型

SrcType 为 0 时读取 FP64，为 1 时读取低 32 位 FP32（载体高位补零）。编码 2 和 3 保留，执行时在读取源寄存器之前触发非法指令异常。

## 编码格式

![FGE](../../../figs/bitfield/svg/Instruction_32bit/FGE.svg)

## 执行方式

任何一个输入是 NaN 时比较结果都为 0。仅信号 NaN 置 NV。

## 示例

左源为 2、右源为 3，结果为 0。
