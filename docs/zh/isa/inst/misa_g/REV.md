# REV

## 说明

将所选位域按字节倒序，结果放在目的寄存器的低位。

## 汇编语法

```asm
rev SrcL,  M, N, ->{t, u, Rd}
```

## 编码格式

![REV](../../../figs/bitfield/svg/Instruction_32bit/REV.svg)

## 执行方式

immr 保存起始位 M，imml 保存位数 N 减一。M 的范围是 0 至 63，N 的范围是 1 至 64。位域越过第 63 位时从第 0 位继续。N 为 8 的倍数时倒转字节次序，其余高位补零；其他宽度正常返回零。

## 示例

若 a0 为 `0x11223344`，`rev a0, 8, 16, ->a1` 取出 `0x2233`，结果为 `0x3322`。同一起点取 12 位时，结果为零。
