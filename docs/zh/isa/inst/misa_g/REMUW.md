# REMUW

## 说明

取两个源寄存器的低 32 位，按无符号整数相除。将余数写入目的寄存器。

## 汇编语法

```asm
remuw SrcL, SrcR, ->{t, u, Rd}
```

## 编码格式

![REMUW](../../../figs/bitfield/svg/Instruction_32bit/REMUW.svg)

## 执行方式

余数等于被除数减去商与除数的乘积。除数为零时，商为零，余数为被除数。每个写回结果都从 32 位符号扩展到 64 位。

## 示例

若两个操作数分别为 17 和 5，商为 3，余数为 2。因此本指令写入 2。

## 汇编索引模式

```asm
remuw a1, a2,           ->t
remuw t#1, t#2,         ->u
remuw u#1, u#2,         ->a3
```
