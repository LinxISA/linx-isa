# BCNT

## 说明

统计所选位域中值为 1 的位数。

## 汇编语法

```asm
bcnt srcL,  M, N, ->{t, u, Rd}
```

## 编码格式

![BCNT](../../../figs/bitfield/svg/Instruction_32bit/BCNT.svg)

## 执行方式

M 是起始位（0 至 63），N 是位数（1 至 64）。字段 imms 保存 M，imml 保存 N 减一。从源的第 M 位开始向高位取 N 位，经过第 63 位后从第 0 位继续。先取到的位是所选位域的最低位。位域为全零时返回 0，全一时返回 N。

## 示例

源值为 `0x1000000000000003`，M = 60，N = 8。选中高四位和低四位，按取位顺序组成 `0x31`。执行 `bcnt a0, 60, 8, ->a1` 后，a1 为 `3`。
