# HL.CCATW

## 说明

从 SrcL 和 SrcR 各取低 32 位，前者放在高半部，后者放在低半部。把拼成的 64 位值逻辑右移 shamt 位，将结果的低、高 32 位分别符号扩展到 64 位，依次写入 Dst0、Dst1。

## 汇编语法

```asm
hl.ccatw SrcL, SrcR, shamt, ->Dst0, Dst1
```

## 编码格式

第 1 段（48 位），从高位到低位依次为 `shamt`（47:41）、`SrcR`（40:36）、`SrcL`（35:31）、`3'b010`（30:28）、`RegDst0`（27:23）、`7'b1011101`（22:16）、`RegDst1`（15:11）、`11'b00000001110`（10:0）。

## 执行方式

shamt 的范围是 0 至 127。移位量为 64 至 127 时，两个结果都为零。两个源操作数都在写回前读取。两个目标为同一通用寄存器时，保留第二次写入的值。两个目标为同一临时队列时，第二项成为最新一项。

## 示例

若 a0 为 1、a1 为 2，执行 `hl.ccatw a0, a1, 1, ->a2, a3` 后，低 32 位为 `0x80000001`，符号扩展后 a2 为 `0xffffffff80000001`，a3 为 0。
