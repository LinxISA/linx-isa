# HL.REMW

## 说明

取两个源寄存器的低 32 位，按有符号整数相除。商向零取整。先将余数写入 Dst0，再将商写入 Dst1。

## 汇编语法

```asm
hl.remw SrcL, SrcR, ->Dst0, Dst1
```

## 编码格式

第 1 段（48 位），从高位到低位依次为 `7'b0000000`（47:41）、`SrcR`（40:36）、`SrcL`（35:31）、`3'b110`（30:28）、`RegDst0`（27:23）、`7'b1010111`（22:16）、`RegDst1`（15:11）、`11'b00000001110`（10:0）。

## 执行方式

余数等于被除数减去商与除数的乘积。除数为零时，商为零，余数为被除数。最小的 32 位有符号整数除以 −1 时，商为该最小值，余数为零。每个写回结果都从 32 位符号扩展到 64 位。

两个源操作数都在写回前读取。两个目标为同一通用寄存器时，保留第二次写入的值。两个目标为同一临时队列时，第二项成为最新一项。

## 示例

若两个操作数分别为 17 和 5，商为 3，余数为 2。Dst0 得到 2，Dst1 得到 3。
