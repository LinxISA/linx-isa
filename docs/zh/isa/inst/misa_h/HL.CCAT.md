# HL.CCAT

## 说明

将 SrcL 放在高 64 位，SrcR 放在低 64 位，拼成一个 128 位值。逻辑右移 shamt 位后，先把结果的低 64 位写入 Dst0，再把高 64 位写入 Dst1。

## 汇编语法

```asm
hl.ccat SrcL, SrcR, shamt, ->Dst0, Dst1
```

## 编码格式

第 1 段（48 位），从高位到低位依次为 `shamt`（47:41）、`SrcR`（40:36）、`SrcL`（35:31）、`3'b001`（30:28）、`RegDst0`（27:23）、`7'b1011101`（22:16）、`RegDst1`（15:11）、`11'b00000001110`（10:0）。

## 执行方式

shamt 的范围是 0 至 127。右移时在高位补零，移出最低位的比特丢弃。两个源操作数都在写回前读取。两个目标为同一通用寄存器时，保留第二次写入的值。两个目标为同一临时队列时，第二项成为最新一项。

## 示例

若 a0 为 1、a1 为 2，执行 `hl.ccat a0, a1, 1, ->a2, a3` 后，a2 为 `0x8000000000000001`，a3 为 0。
