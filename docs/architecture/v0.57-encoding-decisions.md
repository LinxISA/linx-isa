# LinxISA v0.57 Encoding Decisions

This page records the normative v0.57 encoding assignments. Encodings not
named here remain defined by the canonical v0.57 opcode catalog.

## Stability Rule

Established byte encodings, decode legality, and reserved behavior remain
stable for every form not listed here. Legacy compatibility spellings are not
revived; active sources accept only canonical v0.57 spellings.

## TMA Function Window

All rows below use the TMA header pattern:

`31..27=DataType`, `26..25=00`, `24..20=Function`,
`19..15=00010`, `14..0` fixed block-split tail.

The mask excludes `DataType` and includes the function selector and fixed tail:
`mask=0x07ffffff`.

| Function | Alias | Match | Decision |
|---:|---|---:|---|
| 0 | `BSTART.TLOAD` | `0x00011181` | canonical |
| 1 | `BSTART.TSTORE` | `0x00111181` | canonical |
| 2 | `BSTART.TMOV` | `0x00211181` | canonical |
| 3 | `BSTART.TPREFETCH` | `0x00311181` | new v0.57 selector |
| 4 | `BSTART.MGATHER` | `0x00411181` | new v0.57 selector |
| 5 | `BSTART.MSCATTER` | `0x00511181` | new v0.57 selector |
| 6 | `BSTART.MGATHER.MASK` | `0x00611181` | new v0.57 selector |
| 7 | `BSTART.MSCATTER.MASK` | `0x00711181` | new v0.57 selector |
| 8 | `BSTART.MGATHER.CAS` | `0x00811181` | new v0.57 selector |
| 9..31 | reserved | — | illegal instruction |

`BSTART.TPREFETCH` deliberately occupies the adjacent function slot after
`TLOAD`, `TSTORE`, and `TMOV`. It is not allocated in a distant extension
window.

## `TPREFETCH` Encoding Contract

`BSTART.TPREFETCH` is encoded as TMA `Function=3`:

- mask: `0x07ffffff`
- match: `0x00311181`
- `DataType` remains the existing 5-bit TMA data-type field.

Architecturally, `TPREFETCH` is `TLOAD` without destinations. It uses the same
address-generation and memory contract as `TLOAD`, but it must not allocate or
write a tile destination.

## PTO Selector Manifest Rule

The exact 111-operation PTO map is authoritative in:

`isa/v0.57/state/pto_encoding_map.json`

The source workbook is normalized into `pto_ops.json` and is never read by the
normal build. Workbook row order does not allocate encodings. Existing
Established TEPL selectors are preserved; new selectors use only
`0x02B..0x048`, `0x080..0x08B`, `0x0C0..0x0C8`, and `0x0E0..0x0E3`.
All other 10-bit values remain reserved.

## CUBE Function Map

The PTO matrix rows use the inherited CUBE family plus named aliases:

| Function | Canonical alias | PTO spelling |
|---:|---|---|
| 0 | `BSTART.TMATMUL` | `TMATMUL` |
| 1 | `BSTART.TMATMUL.BIAS` | `TMATMUL_BIAS` |
| 2 | `BSTART.TMATMUL.ACC` | `TMATMUL_ACC` |
| 4 | `BSTART.TMATMULMX` | `TMATMUL_MX` |
| 16 | `BSTART.TGEMV` | `TGEMV` |
| 17 | `BSTART.TGEMV.BIAS` | `TGEMV_BIAS` |
| 18 | `BSTART.TGEMV.ACC` | `TGEMV_ACC` |
| 20 | `BSTART.TGEMVMX` | `TGEMV_MX` |

Documented named aliases also exist at functions 5, 6, 21, and 22 for the
micro-scaled bias and accumulate variants. The generic
`BSTART.CUBE Function, DataType` form remains legal; function
values without a named alias therefore retain only that generic decode. The
generic form excludes the 13 named functions above, so each raw word has one
canonical decode and the encoding-space overlap gate remains clean.

## Scalar Encoding Evidence

v0.57 adds the following 32-bit encodings from LinxISA/linx-isa#139 while
leaving the existing 48-bit `HL.CAS*` forms unchanged:

| Form | Mask | Match | v0.57 decision |
|---|---:|---:|---|
| `CASB` | `0x0000707f` | `0x0000001b` | 32-bit local byte compare-and-swap |
| `CASH` | `0x0000707f` | `0x0000101b` | 32-bit local halfword compare-and-swap |
| `CASW` | `0x0000707f` | `0x0000201b` | 32-bit local word compare-and-swap |
| `CASD` | `0x0000707f` | `0x0000301b` | 32-bit local doubleword compare-and-swap |
| `DMA` | `0xfe007fff` | `0x0000700b` | 32-bit encoding of the inherited fixed 64-byte copy |

For `DMA`, `SrcL` remains the source address and `SrcR` remains the destination
address. PR #139 does not allocate a control-word format; its provisional
“control parameters” wording is non-normative.

## Rejection Rules

Assemblers, decoders, and tests must reject:

- generic mixed TMA source forms,
- unassigned TMA functions,
- retired compatibility spellings from pre-v0.57 sources,
- PTO selector numbers not present in the frozen v0.57 manifest.
