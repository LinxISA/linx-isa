# QEMU PTO Tile execution status

This page defines the active LinxISA v0.58 QEMU bring-up boundary. The
normative instruction, encoding, and engine assignments come from
`isa/v0.58/linxisa-v0.58.json`; QEMU source and generated coverage reports are
implementation evidence only.

## Engine boundary

PTO Tile operations execute on exactly four semantic engines:

| Engine | Responsibility | Current v0.58 evidence |
| --- | --- | --- |
| VEC | Element-wise arithmetic, logic, comparison, selection, and simple lane transforms | Linx-TileOP-API static/assembly tests plus nested SuperNPU VEC corpus |
| SFU | Operations that require complex-function or irregular hardware | Linx-TileOP-API static/assembly tests plus nested SuperNPU SFU corpus |
| TLSU | Tile load/store, movement, descriptor, and memory-access behavior | Linx-TileOP-API static/assembly tests plus nested SuperNPU memory corpus |
| CUBE | Matrix and matrix-vector execution | Linx-TileOP-API static/assembly tests plus nested SuperNPU cube corpus |

`TEPL` is the unchanged Mode/Function binary carrier shared by VEC and SFU.
It is not a semantic engine. `BSTART.VEC` and `BSTART.SFU` are accepted
assembly aliases; they allocate no new encoding space. TMA and generic
`BSTART.TMA` are retired names and MUST NOT be used by active source,
coverage classification, or new tests.

The old `tile`, `pto_parity`, and `deepseek_tilekernels` AVS suites depended on
the retired v0.57 PTO-Kernel API. Their sources are preserved under
`avs/archive/v0.57/qemu/` and MUST NOT be cited as v0.58 evidence. Rebuilding
direct-boot runtime coverage against the v0.58 API is tracked by
[issue 169](https://github.com/LinxISA/linx-isa/issues/169).

## Evidence contract

The current fail-closed component checks are:

```bash
make -C tools/Linx-TileOP-API check
python3 workloads/pto_kernels/scripts/check_supernpu_v058.py
```

These checks prove the v0.58 API/corpus contract but do not substitute for
QEMU execution. Until issue 169 is closed by fresh exact-pin runtime evidence,
the runtime Tile AVS state is explicitly open. A skipped, missing, pending, or
archived test is not passing evidence.

Current decoder/source mapping is generated by:

```bash
python3 tools/bringup/report_qemu_isa_coverage.py \
  --spec isa/v0.58/linxisa-v0.58.json \
  --qemu-root emulator/qemu \
  --qemu-meta emulator/qemu/target/linx/linx_opcode_meta_gen.h \
  --report-out docs/bringup/gates/qemu_isa_coverage_latest.json \
  --out-md docs/bringup/gates/qemu_isa_coverage_latest.md
```

Runtime claims require the independently audited executable report in
addition to decoder/source mapping. Historical PTO v0.2 and LinxISA v0.57
bring-up notes are archived under `docs/archive/v0.57/` and are non-normative.
