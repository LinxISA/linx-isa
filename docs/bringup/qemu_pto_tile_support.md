# QEMU PTO Tile execution status

This page defines the active LinxISA v0.58 QEMU bring-up boundary. The
normative instruction, encoding, and engine assignments come from
`isa/v0.58/linxisa-v0.58.json`; QEMU source and generated coverage reports are
implementation evidence only.

## Engine boundary

PTO Tile operations execute on exactly four semantic engines:

| Engine | Responsibility | AVS sources |
| --- | --- | --- |
| VEC | Element-wise arithmetic, logic, comparison, selection, and simple lane transforms | `avs/qemu/tests/10_tile_vec_sfu.cpp`, `10_tile_vec_sfu_asm.S` |
| SFU | Operations that require complex-function or irregular hardware | `avs/qemu/tests/10_tile_vec_sfu.cpp`, `10_tile_vec_sfu_asm.S` |
| TLSU | Tile load/store, movement, descriptor, and memory-access behavior | `avs/qemu/tests/10_tile_tlsu.cpp` |
| CUBE | Matrix and matrix-vector execution | `avs/qemu/tests/10_tile_cube.cpp`, `10_tile_cube_asm.S` |

`TEPL` is the unchanged Mode/Function binary carrier shared by VEC and SFU.
It is not a semantic engine. `BSTART.VEC` and `BSTART.SFU` are accepted
assembly aliases; they allocate no new encoding space. TMA and generic
`BSTART.TMA` are retired names and MUST NOT be used by active source,
coverage classification, or new tests.

The currently pinned QEMU leaf predates full v0.58 consumer closure. In
particular, its exact typed TLSU handlers cover Functions 0..8; the shared Tile
forms at Functions 9..14 remain an explicit downstream implementation gap.
The checked-in `*_latest` breadth reports are v0.57 compatibility snapshots
until they are regenerated by the QEMU hard-break upgrade and MUST NOT be cited
as v0.58 conformance evidence.

## Evidence contract

The focused runtime command is:

```bash
QEMU=$PWD/emulator/qemu/build/qemu-system-linx64 \
  python3 avs/qemu/run_tests.py --suite tile --timeout 40
```

The `tile` suite enables the TLSU descriptor cases with
`LINX_TEST_ENABLE_TLSU_DESC=1`. Unsupported selector, dtype, layout, or shape
tuples MUST trap before queue publication or destination mutation; a skipped,
missing, or pending test is not passing evidence.

Current decoder/source mapping is generated by:

```bash
python3 tools/bringup/report_qemu_isa_coverage.py \
  --spec isa/v0.58/linxisa-v0.58.json \
  --qemu-root emulator/qemu \
  --qemu-meta emulator/qemu/target/linx/linx_opcode_meta_gen.h \
  --report-out docs/bringup/gates/qemu_isa_coverage_latest.json \
  --out-md docs/bringup/gates/qemu_isa_coverage_latest.md
```

Runtime claims require the independently audited executable report in
addition to decoder/source mapping. Historical PTO v0.2 and LinxISA v0.57
bring-up notes are archived under `docs/archive/v0.57/` and are non-normative.
